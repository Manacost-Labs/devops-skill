# Windows Server baseline

Confirm edition/version, activation/support status, hostname, virtualization, uptime, timezone/time sync, disk/inode-equivalent headroom, installed roles/features, automatic services, firewall profiles, listeners, patch/reboot state, and a console or second remote path.

For a new server, establish a named operator using least privilege, an approved remote-management path, a narrow firewall policy, time sync, maintenance policy, and documented break-glass access. Do not combine role installation, service deployment, firewall changes, and access-policy changes in one opaque operation.
