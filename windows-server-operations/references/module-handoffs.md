# Ownership handoffs

Provide confirmed facts, missing evidence and next action, not guessed commands.

- AD DS/GPO objects and policy intent: identity-directory-operations. AD forest/DC recovery, AD CS/PKI authority, DFS/cluster topology and unsupported roles need the named specialist/runbook.
- Privileged access, service/gMSA identity, credential/key rotation/revocation: secrets-access with the directory/PKI/host executor.
- Host certificate installation/key access and binding intent: this module; public TLS/IIS/reverse-proxy service-path acceptance: network-edge with application owner.
- SMB/NTFS, local task definitions and standalone host storage: this module; provider disks/APIs and IaC source/state: provider/IaC modules.
- File/host backup and VSS/Windows restore: this module with selected backup product/application owner. Database resilience covers only its declared PostgreSQL/Redis/MySQL/MariaDB methods; SQL Server/Exchange recovery requires a specialist.
- Containers and database engine/application state retain their runtime/data owners; do not restart or repair them as generic host maintenance.
- Reliability owns telemetry/alerts, incident acceptance and observation: provide UTC timeline, service/user impact, bounded IDs/counters and verification gaps.
