# Module handoffs

Provide confirmed facts, not guesses.

- Docker: host, disk/inode finding, relevant container/service names, Docker status, and timestamped evidence.
- Network edge: listener, local health result, DNS/TLS/proxy symptom, firewall facts, and expected external route.
- Reliability: symptom timeline, affected host/services, available metrics/logs, current remediation, and alert gap.
- Data resilience: data location, backup evidence, change/migration intention, RPO/RTO known or unknown, and recovery risk.
- Cloud: target profile, region/project, instance identity, console availability, and cost/security constraints.
